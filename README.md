# Arte Digital

## Sobre

Nesta disciplina aprendi os fundamentos da criação artística utilizando ferramentas digitais. Estudei conceitos de design, composição visual, cores e edição de imagens, desenvolvendo projetos criativos para diferentes mídias digitais.

## O que aprendi

- Conceitos de arte e design digital;
- Teoria das cores e composição visual;
- Edição e manipulação de imagens;
- Criação de ilustrações e peças gráficas;
- Uso de ferramentas digitais para produção visual;
- Desenvolvimento da criatividade e comunicação visual.

## Conclusão

A disciplina me ajudou a entender como utilizar recursos digitais para criar conteúdos visuais de forma criativa e profissional, aplicando princípios de design em diferentes projetos.
