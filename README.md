# 🎨 Arte Digital

## 📚 Sobre

Nesta disciplina, aprendi os fundamentos da **criação artística utilizando ferramentas digitais**, explorando conceitos de design, composição visual, cores e edição de imagens.

Durante os estudos, desenvolvi projetos criativos voltados à produção de conteúdos visuais para diferentes mídias digitais.

---

## 🧠 O que aprendi

| Área                        | Conhecimentos                                        |
| --------------------------- | ---------------------------------------------------- |
| 🎨 **Design**               | Fundamentos de arte e design digital                 |
| 🌈 **Cores**                | Teoria das cores e combinação de elementos           |
| 🖼️ **Edição**              | Manipulação e edição de imagens                      |
| ✏️ **Ilustração**           | Criação de ilustrações e peças gráficas              |
| 💻 **Ferramentas digitais** | Utilização de recursos para produção visual          |
| 💡 **Criatividade**         | Desenvolvimento da criatividade e comunicação visual |
